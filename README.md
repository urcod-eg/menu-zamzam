# URCOD Digital Menu — الإصدار 2.0

منيو إلكتروني لكل مطعم: **لينك واحد** بيفتح المنيو على طول، ولوحتين مخفيين جوه نفس اللينك.

| مين | إزاي يدخل | بيدخل بإيه |
|---|---|---|
| **الزبون** | يفتح اللينك | — |
| **الإدارة** (صاحب المطعم) | ٧ ضغطات على لوجو المطعم | كلمة سر + كلمة أمان (من المطوّر على واتساب) |
| **المطوّر** (URCOD) | «صُنع بواسطة URCOD» › ١٠ ضغطات على لوجو URCOD | كلمة سر + كلمة أمان بتاعتك |

مفيش بريد، ومفيش تأكيد، ومفيش لوحة خارجية. الخروج من أي لوحة بيرجّع للمنيو.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` + `app.js` | المنيو، والدخول المخفي |
| `admin.html` + `admin.js` + `excel.js` | لوحة الإدارة: الأقسام، والأصناف، والعروض، والإعلانات، والإعدادات، وExcel |
| `dev.html` + `devpage.js` | صفحة المطوّر: الهوية، والترخيص، وحساب الإدارة، والصور، والملاحظات |
| `data.js` | قراءة المنيو بأقل استهلاك (قراءتين أول مرة، وبعدها ١ أو ٠) |
| `config.js` | **الملف الوحيد اللي بيتغيّر لكل عميل** |
| `firestore.rules` | قواعد الأمان، وبتتلصق في Firebase |
| `icons/` | أيقونة التطبيق، وهي نفسها لوجو المطعم في الهيدر لو مفيش رابط لوجو |
| `templates/menu-template.xlsx` | قالب Excel للأصناف |
| `tools/new_client.py` | تجهيز نسخة عميل في أمر واحد (مابيترفعش) |

## عميل جديد

### ١. Firebase (مشروع جديد باسم `menu-اسم-العميل`)
1. **Firestore Database** (مش Realtime) › Standard › `europe-west1` › Production mode.
2. **Authentication** › Email/Password › Enable. ده بيستخدمه البرنامج داخليًا، مفيش إيميلات حقيقية.
3. **Authentication › Settings › Authorized domains** › `urcod-eg.github.io`.
4. **Project settings** › Web app `</>` › انسخ الـ config واحفظه في `firebase.txt`.

### ٢. جهّز النسخة على جهازك
```
python tools/new_client.py --id menu-zamzam --name-ar "زمزم" --name-en "Zamzam" --palette green --logo logo.png --firebase firebase.txt
```
أو يدوي:
- `config.js`: `clientId` + `useSample: false` + الأربع قيم من الـ config.
- `firestore.rules`: بدّل `__DEV_LOGIN__` بـ `dev.المعرّف@urcod.app`، مثلًا `dev.menu-zamzam@urcod.app`.
- `icons/`: لوجو المطعم.

### ٣. ارفع
- Firestore › Rules › الصق `firestore.rules` › **Publish**.
- repo جديد (Public) بنفس الاسم › ارفع كل الملفات **ماعدا مجلد tools** › Settings › Pages › main.

### ٤. جهّز من جوه المنيو
1. افتح اللينك › قايمة النقط › «صُنع بواسطة URCOD» › **١٠ ضغطات على لوجو URCOD**.
2. **أول مرة بس:** اختار كلمة سر وكلمة أمان للمطوّر. **اعملها على طول بعد الرفع**، لأن أول واحد يعملها بيبقى هو المطوّر.
3. في صفحة المطوّر:
   - **الهوية** › الاسم والعبارة واللون › حفظ. أول حفظ بيعمل منيو تجريبي يبدأ منه الأدمن.
   - **الترخيص** › المدة.
   - **حساب الإدارة** › واتساب صاحب المطعم › «توليد تلقائي» › «إنشاء حساب الإدارة» › **إرسال واتساب** أو **نسخ**.
4. صاحب المطعم: ٧ ضغطات على اللوجو › كلمة السر + كلمة الأمان › يعدّل وينشر.

## أسئلة متكررة
- **صاحب المطعم نسي كلمة السر؟** صفحة المطوّر › حساب الإدارة › بيانات جديدة › إرسال. القديمة بتبطل على طول.
- **عايز تغيّر كلمة سر المطوّر؟** صفحة المطوّر › آخر قسم.
- **نسيت كلمة سر المطوّر؟** Firebase › Authentication › امسح المستخدم `dev.…@urcod.app`. وبعدين Firestore › `public/meta` › خلّي `devReady` = false. وبعدين ١٠ ضغطات تاني واختار جديد.
- **الترخيص خلص؟** الأدمن بيقدر يفتح اللوحة ويشوف، بس النشر بيترفض من Firebase نفسه لحد ما تجدّد.
- **تنبيه GitHub على API Key؟** Close alert › Won't fix. ده مفتاح عام بطبيعته، والحماية في القواعد.
