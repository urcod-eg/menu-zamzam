## الاستهلاك على الخطة المجانية

الزبون بيقرا مستندين بس:

- `public/meta`: رقم الإصدار والترخيص. بيتقري مرة كل ٥ دقايق بالكتير على نفس الجهاز.
- `public/menu`: المنيو كله. بيتقري **بس لما رقم الإصدار يتغيّر**، وبعدها بيفضل على الجهاز.

| الحالة | القراءات |
|---|---|
| أول زيارة | ٢ |
| زيارة تانية والمنيو ماتغيّرش | ١ |
| refresh في خلال ٥ دقايق | ٠ |
| الأدمن عدّل المنيو | ٢ لكل جهاز مرة واحدة |

الحد المجاني ٥٠٬٠٠٠ قراءة في اليوم، يعني حوالي ٢٥ ألف زيارة جديدة يوميًا لكل مطعم. المفضلة وحجم الخط والثيم واللغة والعدّادات كلها على الجهاز، ومفيش ولا قراءة.

> **حجم المستند:** حد Firestore للمستند الواحد ١ ميجا، وده يكفي حوالي ٤٠٠ إلى ٦٠٠ صنف بوصف عربي وإنجليزي. الصور **روابط** مش ملفات جوه المستند.

## الصور من غير Firebase Storage

الـ Storage بقى محتاج خطة Blaze، فالصور مابتتخزنش في Firebase خالص. الأدمن عنده طريقتين:

1. **رابط صورة** (`https://…`): بيشتغل على طول من غير أي تجهيز.
2. **صورة من الجهاز:** أي صيغة المتصفح يقدر يفتحها (PNG، JPG، WebP، GIF، AVIF، BMP، وHEIC على آيفون). الصورة بتتصغّر على الموبايل (الصنف ٩٠٠ بكسل، والإعلان ١٤٠٠، واللوجو ٥١٢) وبتتحوّل WebP، وبعدين بتترفع على **repo صور منفصل على GitHub** خاص بالعميل وبتتعرض من GitHub Pages.

الصورة القديمة بتتمسح من الـ repo لوحدها بعد ما الأدمن ينشر التعديل اللي بدّلها أو شالها.

### تفعيل رفع الصور لعميل (مرة واحدة)
1. اعمل repo **عام** للصور بس، مثلًا `اسم-العميل-menu-img`، وفيه ملف README عشان الفرع `main` يتعمل.
2. Settings › Pages › Deploy from branch › `main` / root.
3. GitHub › Settings › Developer settings › **Fine-grained tokens** › Generate:
   - Repository access: **Only select repositories** › repo الصور بس
   - Permissions › Repository › **Contents: Read and write**
   - Expiration: سنة، وحط تذكير تجدّده.
4. في `tools/seed.html` › قسم ٥ › املأ owner و repo والـ token › **اختبار الاتصال** › **حفظ**.

> **ليه repo منفصل؟** الـ token بيتقري من موبايل الأدمن عشان يرفع. لو اتسرق، أقصى حاجة يقدر حد يعملها إنه يغيّر صور. مايقدرش يلمس كود المنيو ولا الـ repo الأساسي.

## تجهيز عميل جديد بالسكريبت (الطريقة السريعة)

```bash
python tools/new_client.py --id cafe-elnil --name-ar "كافيه النيل" --name-en "Nile Cafe" \
  --palette navy --logo ~/clients/nile/logo.png \
  --dev-email you@example.com --dev-panel-url https://urcod-eg.github.io/menu-dev/ \
  --firebase ~/clients/nile/firebase.txt
```

السكريبت بيعمل الحاجات دي لوحده:
- مجلد جديد جنب المشروع.
- `config.js` جاهز.
- القواعد فيها بريدك.
- الاسم ولون الثيم في الـ manifest والصفحات.
- الأيقونات من اللوجو، ولو مفيش Pillow اتسطّب: `pip install pillow`.
- ملف **HANDOVER.md** فيه الخطوات اللي فاضلة بالقيم بتاعة العميل ده.

ملف `firebase.txt` = كود الإعدادات زي ما بتنسخه من Firebase Console.

وبعد كده، من **لوحة المطوّر**: تضيف العميل، وتعمل حساب المطوّر في مشروعه، وترفع المنيو التجريبي، وتظبط الترخيص، وتعمل الأدمن. ومن غير ما تفتح Console تاني.

## خطوات تجهيز عميل جديد (يدوي)

على نفس طريقتك: تجهّز كل حاجة في مجلد على جهازك الأول، وبعدين ترفع.

### ١. مشروع Firebase جديد (خطة Spark)
1. أنشئ مشروع جديد باسم العميل.
2. **Firestore Database** › Create database › Production mode › أقرب منطقة (مثلًا `europe-west`).
3. **Authentication** › Sign-in method › فعّل **Email/Password**.
4. **Project settings** › Your apps › Web app (`</>`) › انسخ `apiKey` و`authDomain` و`projectId` و`appId`.
5. **Authentication** › Settings › Authorized domains › ضيف `اسم-الحساب.github.io`.

### ٢. قواعد الأمان
Firestore › Rules › الصق محتوى `firestore.rules` › **Publish**.

### ٣. حساب المطوّر (مرة واحدة لكل مشروع)
- **الأسهل:** بدّل `__DEV_EMAIL__` في `firestore.rules` ببريدك (السكريبت بيعمل ده لوحده). وبعدين من لوحة المطوّر › «اعمل حساب المطوّر» › أكّد البريد، والصلاحية هتتفعّل لوحدها.
- **يدوي:** Authentication › Add user › انسخ الـ UID. وبعدين Firestore › `roles` › Document ID = الـ UID › `role` = `dev`.

### ٤. ملف config.js
```js
clientId: "اسم-مختصر-للعميل",
useSample: false,
firebase: { apiKey: "...", authDomain: "...", projectId: "...", appId: "..." }
```

### ٥. هوية العميل
- `manifest.webmanifest`: الاسم والاسم المختصر و`theme_color`.
- `icons/`: بدّل الـ ٣ أيقونات بلوجو المطعم بنفس المقاسات. الـ maskable يكون فيه هامش حوالي ١٢٪.
- `sw.js`: غيّر `VERSION` مع كل رفع جديد.

### ٦. الرفع والتجهيز
1. ارفع المجلد على repo جديد وفعّل GitHub Pages.
2. افتح `https://.../tools/seed.html` وادخل بحساب المطوّر.
3. **رفع المنيو التجريبي**، وبعدين **الترخيص** (مثلًا +٧ أيام تجربة)، وبعدين **صلاحية الأدمن** بالـ UID بتاع حساب المطعم، وبعدين **رفع الصور** لو هتفعّله.
4. افتح المنيو واتأكد إن كله ظاهر.

## لوحة الإدارة (`admin.html`)

- الدخول: من `admin.html` مباشرةً، أو ٧ ضغطات على لوجو المطعم في المنيو.
- **التبويبات:** الرئيسية، الأقسام، الأصناف، الإعلانات، الإعدادات.
- **الأصناف:** صورة، واسم ووصف بالعربي والإنجليزي، وقسم، وسعر واحد أو أحجام، ونوع الخدمة، وجديد، ومتاح، والعرض بأنواعه الخمسة مع معاينة «الزبون هيشوف: …».
- **الأسعار:** بتقبل أرقام عربي وإنجليزي، وكسور بـ «٫» أو «.» أو «,»، ومابتقبلش سالب ولا نص.
- **العروض:** اللوحة بترفض أي «خصم» يطلع السعر فيه أكبر من أو بيساوي الأصلي، وبتطلب تاريخ انتهاء. حالة كل عرض بتظهر: نشط، مجدول، منتهي، متوقف.
- **الأقسام:** قبل ما تمسح قسم فيه أصناف بتختار تنقلها لقسم تاني أو تمسحها معاه. ومفيش قسم بيتمسح وجواه أقسام فرعية.
- **كل التعديلات بتتجمّع على الجهاز.** زرار «نشر التعديلات» بيبيّن عددها، والنشر = كتابتين بس في Firestore مهما كان عدد التعديلات. ولو الصفحة اتقفلت قبل النشر، أول ما الأدمن يدخل تاني بيلاقي «استرجاع».
- **لو جهازين عدّلوا في نفس الوقت:** التاني بيترفض بدل ما يمسح شغل الأول، وبتظهر له رسالة يفتح الصفحة تاني.
- **الترخيص:** لو منتهي، اللوحة بتفتح للعرض بس، والنشر بيترفض على السيرفر كمان.

## استيراد المنيو من Excel

من اللوحة: **الأصناف ← Excel**، أو الزرار اللي في الرئيسية.

### القالب
فيه ٥ أوراق: تعليمات، الأقسام، الأصناف، الأحجام، العروض. الصف الأول عنوان بالعربي، والتاني اسم العمود الثابت، والبيانات من الصف التالت. والخانات اللي ليها قيم محددة فيها قوائم اختيار جاهزة.

### نوع السعر
| النوع | تكتب فين |
|---|---|
| **سعر واحد** | عمود «السعر» في ورقة الأصناف، ومفيش صفوف للصنف ده في ورقة الأحجام |
| **أحجام** | عمود السعر فاضي، وفي ورقة الأحجام صف لكل حجم فيه معرّف الصنف ورمز الحجم والسعر |

البرنامج بيرفض صنف «سعر واحد» من غير سعر، وصنف «أحجام» من غير ولا حجم، وصف حجم لصنف سعره واحد.

### الوضعين
- **تحديث المنيو الحالي** (الافتراضي): المعرّف الموجود بيتعدّل، والجديد بيتضاف، واللي مش في الملف بيفضل. الخانة الفاضية في عمود اختياري معناها «سيب القيمة القديمة». استيراد نفس الملف مرتين مابيكررش حاجة.
- **منيو جديد بالكامل:** بيستبدل الأقسام والأصناف كلها، ومحتاج تأكيد صريح. الإعلانات والإعدادات مابتتغيّرش.

### الأمان والفحص
- الفحص كله قبل أي تغيير، وبيظهر ملخص بعدد الجديد والمتعدّل.
- كل خطأ برقم الصف وحرف العمود واسمه، وفيه زرار «تقرير» بينزّل الأخطاء في ملف Excel.
- **لو فيه خطأ واحد، مفيش أي حاجة بتتغيّر.**
- القيم بتتقبل بالعربي أو الإنجليزي: «متاح» أو available، و«نعم» أو 1، والأرقام العربي والكسور. والتاريخ بأي شكل من دول: `2026-12-31 23:59` أو `31/12/2026 23:59` أو خانة تاريخ عادية في Excel.
- الحد: ٥ ميجا و٣٠٠٠ صف. والملف مابيقدرش يلمس الترخيص ولا الصلاحيات، لأن الاستيراد بيعدّل الأقسام والأصناف بس.
- الاستيراد مابيكتبش في Firebase. بيتطبّق على التعديلات، وبعدين الأدمن يدوس «نشر التعديلات» (كتابتين بس).

### تصدير المنيو الحالي
زرار «المنيو الحالي» بينزّل ملف بنفس أعمدة القالب. عدّل فيه وارفعه بوضع التحديث، أو احتفظ بيه كنسخة احتياطية.

## الترخيص

- بيتسجّل في `public/meta.license`: الحالة، والخطة، وتاريخ الانتهاء (فاضي = دائم)، و`menuOnExpiry` (`show` أو `hide`).
- **الأدمن مايقدرش يعدّله.** القواعد بتسمح له يرفع رقم الإصدار بس.
- **الحفظ بيتمنع على السيرفر** لو الترخيص منتهي أو موقوف، والفحص بوقت Firebase نفسه (`request.time`) مش بساعة الموبايل.
- لو `menuOnExpiry = hide`، الزبون بيشوف رسالة «المنيو مش متاح دلوقتي». ده قرار بتاخده إنت من أداة المطوّر.

## الدخول المخفي

- **٧ ضغطات** على لوجو المطعم: دخول الأدمن.
- **١٠ ضغطات** على لوجو URCOD في صفحة «صُنع بواسطة URCOD»: دخول المطوّر.
- الدخول الحقيقي بـ Firebase Authentication، وبعده بيتفحص `roles/{uid}`.
- بعد ٥ محاولات غلط، الجهاز بيتقفل دقيقة، غير حماية Firebase نفسها.

## شكل البيانات

افتح `sample-menu.js`، هتلاقي كل حقل وقيمه المسموحة متكتبة جنبه. أهمها:

- **القسم:** `parentId` بقيمة `null` للقسم الرئيسي. `available: false` بيخلي القسم يظهر باهت، و`hidden: true` بيخفيه خالص.
- **الصنف:** `priceType` إما `single` ومعاه `price`، أو `variants` ومعاه `[{id, price}]`. و`service` قيمته `both` أو `delivery_only` أو `pickup_only`.
- **العرض:** `type` واحد من دول:
  - `percent` ومعاه `value`
  - `amount` ومعاه `value`
  - `price` ومعاه `price`، أو `prices: {S: ..}` لكل حجم
  - `free_delivery`
  - `custom` ومعاه `text`

  ومع أي نوع: `startAt` و`endAt` و`enabled`.
- **الإعلان:** `theme` قيمته `green` أو `amber` أو `rose` أو `blue` أو `dark`، و`image` اختياري، و`kicker` و`title` و`body`، و`startAt` و`endAt` اختياريين.
- **ألوان المطعم:** `brand.palette` قيمته `green` أو `navy` أو `maroon` أو `coffee` أو `teal`. كلها متجرّبة على الثيمين عشان النص يفضل مقروء.
